# Changelog

- System mode (`-fsys=s2`) resolves the selected installation through `pkg-config` and honors the requested linkage.
- Devenv tasks build the requested package outputs from the project shell.
- The standalone consumer forwards target, linkage, runtime/provider, cache, prefix, job-count, summary and program arguments; it runs only when the executor supports it.
- Nix package metadata identifies Apache-2.0 and the LLVM runtime exception.
- ELF dynamic builds install `libs2cpp.so.0.16.0` and the three verbatim LLVM runtime licence texts.
- The shared install uses relocatable library search paths and includes Abseil's complete 153-unit source closure.
- Nix provides static, shared and default outputs from one source-only derivation.
- The fork's own files now have an owner-authorized Apache-2.0 grant; upstream files retain their original terms.
- The upstream README is preserved byte-for-byte as `README.upstream.md`; fork-specific build and API guides describe the Zig package.
- WASI consumers link SDK 34's `libc++`, `libc++abi` and `libunwind`; Darwin builds link CoreFoundation.
- Abseil portability fixes cover hosted Hexagon, WASI arena ownership, PowerPC32 musl stack traces and NetBSD locale handling.
- S2 big-number parsing passes character pointers to `std::from_chars`, avoiding implementation-specific string-view iterator conversion.
- WASI SDK 34 has an opt-in provider; a Zig 0.16 standard-library patch enables page allocation and finite atomic waits without shipping compiler sources.
- `CellId` neighbor queries support level-30 cells, and face-position construction rejects faces outside 0–5.
- Zig index checks prevent narrowing past the bridge's C `int`; `Coverer` rejects oversized options.
- The C bridge validates caller inputs and reports invalid geometry, allocation failures and count overflow as status results.
- Added a deterministic smoke target, independent fixture oracles and a separate Zig consumer package.
- The typed Zig facade exposes S2 geometry values and operations, with `c` as the raw bridge escape hatch.
- The package builds pinned S2 and vendored Abseil sources, installs their public headers and bridge header, and defaults to static linkage with selectable shared linkage.
